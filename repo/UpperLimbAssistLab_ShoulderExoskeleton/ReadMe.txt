The model was developed and used in OpenSim version 3.1.

This .zip folder contains a file and a folder:
----------------------------------------------
File: 'UpperLimbAssistLab_ShoulderExoskeleton.osim'
This is the model file that includes the MoBL-ARMS musculoskeletal model and the exoskeleton model. 

Folder: 'Geometry'
This folder contains a CAD model of the exoskeleton's CAM wheel, as well as bone geometry of the MoBL-ARMS model segments. Make sure OpenSim references this Geometry folder so that you can visualize these model components.
